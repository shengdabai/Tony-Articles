# AI 热点日报｜形式化证明、智能体评测与医疗模型开源

## 黎曼猜想证明据报道通过形式化验证

IT之家援引一位受访数学家的判断称，一位数学家与 Claude 合作完成的黎曼猜想证明已通过 Lean 形式化验证，并经独立核查。形式化验证让其他研究者可以用程序重跑检查。接下来的学术工作包括解释证明为何成立，以及哪些方法可以用于其他问题。 [source](https://www.ithome.com/1/030/677.htm)

## 编码智能体在模拟公司完成不到一成任务

The Decoder 报道，一项实验让编码智能体在有同事、项目看板和聊天记录的模拟公司里工作。Claude Opus 5.5 和 GPT-6 Astra 完整完成的任务都不到一成。对计划引入智能体的团队，整项任务的交付率能反映模型能否找到背景信息、处理交接并满足验收条件。 [source](https://the-decoder.com/ai-coding-agents-ace-isolated-tests-but-complete-fewer-than-one-in-ten-tasks-in-a-simulated-workplace/)

## METR 提醒关注安全评估的速度

研究机构 METR 在 11 月的能力测量更新中指出，现有公开数据仍无法排除未来几年 AI 研究突然加速的可能。如果模型变强的速度超过专家可靠评估新系统的速度，评估结论就可能赶不上部署。发布计划因此需要考虑复测所需的时间。 [source](https://the-decoder.com/ai-is-getting-better-faster-than-experts-can-reliably-test-whether-new-systems-are-safe-metr-warns/)

## 蚂蚁宣布开源百灵医疗健康模型家族

蚂蚁宣布开源的模型涵盖语言、实时音视频、风险预测和安全防护。公司称，最轻量版本可在一台笔记本上部署。开源为医疗团队提供了本地测试的机会。团队可以按任务核对结果，例如检查影像报告是否漏掉关键发现。 [source](https://www.ithome.com/1/030/784.htm)

## 亚马逊据报道洽购 Decart

据 IT之家转述《金融时报》，亚马逊已就收购 AI 初创公司 Decart 展开深入谈判，估值约 75 亿美元。双方最快可能在本周初达成协议，谈判也可能破裂。如果交易落定，值得关注 Decart 的产品是否会接入亚马逊的服务，以及现有客户将如何使用这些产品。 [source](https://www.ithome.com/1/030/797.htm)

## Gemini API 预览按需加载工具定义

Google 在 Gemini API 中预览 Tool Retrieval。模型先看工具名称和短描述，需要时再加载完整参数定义。工具较多的应用可以借此减少每次请求占用的上下文，同时要验证简短描述能否帮助模型选中正确的工具。 [source](https://www.marktechpost.com/2026/11/22/google-gemini-api-tool-retrieval/)

## Perplexity 推出网页变化监控 API

Monitor API 按计划检查网页，在发现相关变化时通过 webhook 向应用发送通知。团队可以把公告更新等重复查询改为订阅，并根据误报率和通知延迟判断是否适合接入现有流程。 [source](https://the-decoder.com/perplexitys-new-monitor-api-turns-web-search-from-a-one-off-query-into-a-nonstop-watchdog/)
