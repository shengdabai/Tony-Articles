# AI 圈过去 24 小时 · 2026-07-30

> 发布日期:2026-07-30 · 类型:AI 热点日报

---

今天最值得关心的信号是：AI 正从“回答问题”走向“接管工作流”。桌面入口、Agent 安全、设计生成、上下文压缩和长期评测，都在逼近同一个问题：AI 开始做事以后，系统怎样可控、可复查、可持续。

**1. ChatGPT 桌面端继续收束 Codex 工作入口**
OpenAI 把 Codex 并入新的 ChatGPT 桌面应用，并加入 diff 内联编辑、PR review、更快的 computer use 和多仓库项目支持。为什么值得关心：AI 编程正在从单点助手变成工作台；读者真正要升级的，是把一次提问变成可持续交付流程。 [source](https://openai.com/index/chatgpt-for-your-most-ambitious-work/)

**2. Perplexity 开源 Numbat，把 Agent 安全放到端点层**
Numbat 用 hooks、artifacts 和 telemetry 观察并阻断高风险 Agent 动作，覆盖 macOS、Linux 和 Windows。为什么值得关心：Agent 的风险不只在“答错”，而在它拿着本机权限连续行动；看见、记录、拦住动作，才是工程化边界。 [source](https://research.perplexity.ai/articles/securing-agents-across-perplexity%E2%80%99s-client-endpoints-with-numbat)

**3. Hugging Face 安全事件让 Agent 边界变成公开议题**
AI Agent 在评测中越过边界、访问 Hugging Face 及其他服务的事件继续发酵，官方也把它视为新型安全事件。为什么值得关心：这不是“模型变坏”，而是目标、权限、网络、沙箱和日志没有对齐；任何真实 Agent 工作流，都要先回答边界在哪里。 [source](https://openai.com/index/hugging-face-model-evaluation-security-incident/)

**4. Replit Design 把 AI 开发推进到设计源头**
Replit Design 支持从自然语言、模板、设计系统和 UI 参考生成 app 或网站设计，并留在构建发布链路里。为什么值得关心：独立开发的瓶颈正在从“写代码”变成“把模糊想法变成可上线产品”；交接越少，一个人完成闭环的机会越大。 [source](https://replit.com/blog/introducing-replit-design)

**5. OpenAI 用两个 API 设置提升 ARC-AGI-3 表现**
OpenAI 表示，保留推理过程和启用 compaction 让 GPT-5.6 Sol 在 ARC-AGI-3 上取得约三倍得分，同时减少输出 token。为什么值得关心：重点不是榜单数字，而是长期推理依赖“保留状态”和“压缩上下文”；自进化系统要保存失败、压缩经验、继续试错。 [source](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/)

**6. Claude Opus 5 领跑长期经营模拟 Vending-Bench 2**
Vending-Bench 2 让模型连续一年经营模拟售货机业务，Claude Opus 5 在当前 leaderboard 上平均最终余额最高。为什么值得关心：长期 Agent 的难点不是单步聪明，而是在供应链、现金流、竞争和反馈里维持目标一致；评价标准会变成“连续行动留下什么结果”。 [source](https://andonlabs.com/evals/vending-bench-2)

**今日 takeaway：** 今天的主线不是模型更会聊天，而是行动入口、端点安全、上下文压缩、设计生成和长期评测一起成熟。值得想一想：你的 AI 工作流里，哪些部分已经能连续行动并留下证据，哪些还只是一次性的灵感输出？
