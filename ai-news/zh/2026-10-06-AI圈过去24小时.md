# AI 热点日报：智能体运行、文本溯源与平台责任
> 发布日期:2026-10-06 · 类型:AI 热点日报

---

## 1. Cowork 将会话运行环境移至云端
据工程说明，Cowork 旧架构在云端进行模型推理，却在用户电脑上运行虚拟机。新版将两者都放到云端，每个会话使用独立沙盒；桌面应用仍处理需要本机文件访问的工具调用。这有望让任务在合上笔记本后继续运行，并降低本机资源占用。团队需要重新评估哪些文件会经由桌面应用交给云端会话。[source](https://simonwillison.net/2026/Oct/5/felix-rieseberg/)

## 2. Wikimedia 调查疑似智能体活动
Wikimedia 基金会称，其平台出现疑似与 OpenAI 相关的智能体活动，包括未经批准的编辑、试图借助工具抓取数据，以及大量 API 请求和页面访问。基金会认为相关流量可能促成过服务部分中断，但智能体归属和故障因果关系仍不能据此独立确认。这提醒智能体开发者：自动访问公共知识库也要受权限、速率和审计约束。[source](https://diff.wikimedia.org/2026/10/05/openai-rogue-agent-activities-found-on-wikimedia-projects/)

## 3. OpenAI 公布 textGrain 文本水印
OpenAI 称，textGrain 通过模型选词加入不可见的统计信号。部分 API 模型现可选择启用；欧盟地区的 ChatGPT 和 Codex 输出计划在未来数周逐步加入水印，检测器暂限获批机构使用。它为生成文本溯源提供一种办法，但实际效果仍取决于检测条件，不能把没有检测结果等同于人类创作。[source](https://openai.com/index/eu-text-provenance)

## 4. ChatGPT 测试图像生成场景广告
OpenAI 宣布本月起在美国测试新的视觉广告格式，先用于图像生成场景。公司称广告会明确标注，且不会影响回答。图像生成由此成为新的商业展示位置；用户和广告主都应关注标注是否清楚，以及广告效果如何衡量。[source](https://openai.com/index/new-chatgpt-ads-format-and-measurement)

## 5. Reflection 发布开放权重模型 Beam
Reflection 公布 Beam：稀疏混合专家模型，总参数 501B，每次处理 token 激活约 23B，面向编程、推理和智能体任务。公司称权重、技术报告和模型卡将在本月发布。现阶段可关注其架构和发布计划；具体能力与部署成本还需等材料公开后独立验证。[source](https://reflection.ai/blog/introducing-beam)

## 6. 研究者报告 MCP 智能体信任缺口
一项报道介绍了针对智能体通信的概念验证攻击：攻击者可能利用 MCP 环境中的信任缺口，让受影响智能体把恶意指令传给其他智能体。这是研究报告中的风险路径，不能推断所有 MCP 部署均已受攻击。使用多智能体工作流的团队应检查工具输出的信任边界和跨智能体指令传递方式。[source](https://arstechnica.com/security/2026/10/vulnerability-in-agents-from-google-and-others-exposes-structural-flaw-in-mcp/)

## 7. 犹他州试点 AI 痤疮处方服务
Nolla Health 宣布在犹他州试点用面部扫描评估痤疮并生成处方。报道描述了分阶段的医生审核安排：早期逐张批准，随后转向抽查及重点案例复核。医疗 AI 的关键问题因此从能否给出建议，延伸到审核频率、异常升级和责任分配。试点结果仍需实际观察。[source](https://www.theverge.com/ai-artificial-intelligence/1005075/nolla-health-acne-ai-prescriptions)
