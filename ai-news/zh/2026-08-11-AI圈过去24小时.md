# AI 圈过去 24 小时 · 2026-08-11

> 发布日期:2026-08-11 · 类型:AI 热点日报

---

今天的核心信号：Agent 正从“会回答”走向“接管流程”。权限、数据和安全边界，正在决定产品能否被托付。

**1. Claude Code 自动模式成为默认**

Claude Code 近期把自动模式设为默认，让开发者不再反复批准每一步。为什么值得关心：AI 编程正在从“会不会写代码”转向“哪些动作可以托付”，权限、回滚和审计会成为标配。 [source](https://x.com/ClaudeDevs/status/2086844755770757531)

**2. 计算机操作 Agent 接近可用临界点**

a16z 汇总的数据显示，计算机操作 Agent 在 OSWorld-Verified 基准上的最佳成绩已明显高于一年前。为什么值得关心：当 Agent 能稳定操作电脑，跨时空连接就会进入文件、浏览器、表格和代码仓库。 [source](https://www.a16z.news/p/can-agents-use-a-computer-yet-weve)

**3. Genie Agents 同时基于数据表和文档运行**

Databricks 介绍了让 Genie Agents 同时连接结构化数据与文档、并保持治理能力的方法。为什么值得关心：企业 Agent 的难点不是多接数据源，而是让权限、血缘、查询和安全一起成立。 [source](https://www.databricks.com/blog/how-ground-genie-agents-both-structured-data-and-documents-without-losing-governance)

**4. Muse Glimmer 获得本地 Agent 推理支持**

SGLang 宣布为 Muse Glimmer 提供 Day-0 支持，面向本地、常驻、多模态 Agent 工作流优化推理。为什么值得关心：如果 30B 级模型能在本地稳定服务 Agent，个人和小团队就能把更多上下文留在自己机器上。 [source](https://www.lmsys.org/blog/2026-08-10-meta-muse-glimmer)

**5. Qwen-MM-Plugins 接入多模态工具链**

Qwen-MM-Plugins 让 Agent 原生处理图片、视频、文档、视频编辑以及 3D/CAD 等任务。为什么值得关心：多模态不是给聊天窗口加“看图”按钮，而是让 Agent 能读材料、改素材、处理真实工作对象。 [source](https://x.com/Alibaba_Qwen/status/2086664887560970531)

**6. OpenAI 推出网络安全模型**

OpenAI 发布 GPT-5.6-Cyber，用于授权漏洞研究、验证和安全测试。为什么值得关心：AI 正在进入攻防工作流，重点不是模型名字，而是能力是否被限定在合法授权、可审计、可复盘的边界内。 [source](https://openai.com/index/expanding-daybreak-as-the-cyber-defense-window-narrows)

**今日 takeaway：** Agent 的下一步不是更像人，而是更像可靠系统。值得想想：你想托付给 AI 的流程，缺的是强模型，还是权限、数据、验证和回滚？
