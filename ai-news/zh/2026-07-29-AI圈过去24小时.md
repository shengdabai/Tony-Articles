# AI 圈过去 24 小时 · 2026-07-29

> 发布日期:2026-07-29 · 类型:AI 热点日报

---

今天最值得关心的核心信号是：AI 正在从「更会回答」继续推进到「更会接管真实工作流」。编程、安全、搜索、语音、本地部署和 Agent 运行环境都在补同一块短板：让模型有边界地行动，并留下可验证的结果。

**1. Codex Security 走向 CLI 与 SDK**
OpenAI 的 Codex Security 文档已经把安全扫描、批量运行、CI 接入和 TypeScript SDK 放在同一套开发入口下，aihot 也把它列为过去 24 小时的重点更新。为什么值得关心：AI 编程工具越像同事，就越需要安全边界、审查接口和自动化证据链；当安全能力进入 CLI 和 SDK，个人开发者也能把「写代码」和「查风险」放进同一条工程流水线。 [source](https://developers.openai.com/codex/security)

**2. Gemini API Managed Agents 默认升级为 3.6 Flash，并加入环境钩子**
Google 发布 Managed Agents 更新：默认模型升级到 Gemini 3.6 Flash，并加入环境 hooks、预算控制、定时触发和免费层访问。为什么值得关心：Agent 真正可用的关键不是更长的演示视频，而是能在工具调用前后被阻断、审计和修正。环境钩子把「让 AI 自主行动」和「让系统可控」接在一起，这是工程化破界的一步。 [source](https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api-3-6-flash-hooks)

**3. OpenRouter 推出 LangChain 专用集成包**
OpenRouter 发布 ChatOpenRouter 集成教程，面向 LangChain 应用提供 400+ 模型接入和自动故障切换。为什么值得关心：模型层正在变成可替换的供应链，而不是一次性绑定的能力。对读者来说，重要的不是今天押中哪一个模型，而是把应用架构做成可路由、可降级、可迁移的系统。 [source](https://openrouter.ai/blog/tutorials/langchain-chatopenrouter-setup)

**4. 豆包搜索服务面向 AI Agent 提供实时可信搜索**
火山引擎上线豆包搜索服务，定位是给 AI Agent 提供实时、可信、可引用的搜索能力。为什么值得关心：Agent 要完成真实任务，不能只依赖模型记忆；它需要外部世界的最新状态，也需要能被追溯的来源。搜索能力进入 Agent 工具箱后，知识召回、事实核验和任务执行会更容易连成闭环。 [source](https://mp.weixin.qq.com/s/1nZqQHYqclsIF6__WLscgA)

**5. Deltafin 尝试在单台 Apple Silicon 上运行 Kimi K3**
Deltafin 项目展示了在单台 Apple Silicon Mac 上运行 Kimi K3 的路径：按需流式加载专家参数、本地磁盘缓存、Metal/MPS 计算，并提供 OpenAI 兼容 API。为什么值得关心：这不是为了证明本地推理一定更快，而是说明超大模型正在被拆成新的部署形态。只要接口兼容、缓存可控、成本透明，本地 AI 就可能从玩具变成私有工作流的一部分。 [source](https://github.com/gavamedia/deltafin)

**6. OpenAI 推出 GPT Transcribe 与 GPT Live Transcribe**
OpenAI API changelog 显示，7 月 28 日发布了面向文件转写和实时低延迟转写的两款新模型，并支持上下文提示、关键词提示和多语言输入。为什么值得关心：语音不是单独的媒体功能，而是把会议、课程、访谈和操作现场接入 AI 工作流的入口。更好的转写能力，意味着更多真实世界信息可以被结构化、检索和复用。 [source](https://developers.openai.com/api/docs/changelog)

**7. Perplexity 推出 Windows 版个人电脑智能体**
Perplexity 发布 Windows 版个人电脑智能体，方向是让 AI 直接进入桌面环境，辅助处理搜索、文件和应用之间的连续任务。为什么值得关心：Agent 的战场正在从网页对话框移动到个人电脑本身。真正改变效率的不是多一个聊天入口，而是让跨应用任务、上下文保存和行动确认变成可连续执行的工作流。 [source](https://x.com/perplexity_ai/status/2082103880155046176)

**今日 takeaway：** 过去 24 小时的主线不是某个模型单点变强，而是 AI 工作流正在补齐行动、检索、桌面入口和本地化部署。值得想一想：你的 AI 系统里，哪些行动已经有明确边界和可复查证据，哪些还只是一次性的对话结果？
