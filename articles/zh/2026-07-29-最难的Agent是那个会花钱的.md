# 最难的 Agent，是那个会花钱的

> 发布日期:2026-07-29 · [中文](../zh/2026-07-29-最难的Agent是那个会花钱的.md) | [English](../en/2026-07-29-the-hardest-agent-spends-money.md)

---

过去一年，大家最常聊的是 Coding Agent。

这很正常。代码天然适合 Agent 先进入。它是文本环境，有文件、有编译器、有测试、有日志、有版本控制，也有回滚。一个 Coding Agent 做错了，通常会留下证据：测试红了，构建失败了，分支坏了。它可以读错误，改文件，再跑一遍。

可是今天的笔记让我看到一个更粗糙，也更接近商业真实世界的方向。

下一个真正难的 Agent，不是会写代码的那个。

而是会花钱的那个。

很多人听到 Marketing Agent，第一反应是：AI 帮我写广告文案、生成标题、做短视频脚本。这个当然有用，但不是核心变化。

真正的 Marketing Agent，不是内容生成器，而是增长循环。

它研究真实用户，把洞察变成创意，把创意投向市场，花钱获得分发，读取数据，砍掉差的，放大好的，然后继续下一轮。

关键不在“生成”，而在“继续下一轮”。

Coding Agent 写错代码，代价常常是一次失败构建，或者几个小时的清理成本。Marketing Agent 如果判断错了，烧掉的是真预算，伤害的是真信任，干扰的是真客户，也可能让系统学会优化一个看起来很好、实际会把生意带偏的指标。

所以，营销比代码更难。

代码主要是在和机器打交道。

营销是在和市场打交道。

## 增长不是一条提示词

最浅的一层 AI 营销，很容易想象：让模型帮你写更好的广告。

这很快会变成基本能力。真正有意思的地方，不是让 AI 写广告，而是搭一个系统，让“好”和“坏”不再由模型自己说了算。

麦肯锡在 2023 年估算，生成式 AI 每年可能创造 2.6 万亿到 4.4 万亿美元的经济价值，其中大约四分之三会集中在客户运营、营销与销售、软件工程、研发这四个领域。[^1] 这个巨大数字本身反而没那么重要。真正值得注意的是：营销和销售，被放在了和软件工程同一组高价值场景里。

为什么？

因为它们都在变成系统。软件不再只是一个人坐在编辑器前写代码，而是规划、生成、测试、审查、部署、观察、修复的一整套循环。营销也一样：研究、创意、投放、测量、预算分配、复盘迭代。

但营销有一个残酷差异。

编译器不会在意你的品牌气质。测试套件不会因为竞争对手突然降价而改变行为。市场就不一样了。人有情绪，平台有激励，竞争对手会反应，归因常常不完整。一个活动看上去效果很好，也可能只是在吸引错误的人。

所以问题不是：AI 能不能做营销素材？

当然能。

更好的问题是：人能不能设计出一个增长循环，让 AI 在里面运行，同时不悄悄把生意变蠢？

## 铁轨已经铺了一半

这件事不是科幻。

广告平台其实已经把很多基础设施准备好了。Meta 的 Marketing API 让开发者可以用程序创建和管理 campaign、ad set、广告和报表流程。[^2] Google 的 Performance Max 也被官方描述为一种以目标为导向的广告活动类型，可以从一个 campaign 触达 Google Ads 的多渠道库存，并围绕转化目标做优化。[^3]

换句话说，铁轨已经在那儿。

你可以用代码创建广告活动，可以拉取表现数据，可以在平台规则内自动调整出价和预算，可以生成创意，可以把客户数据、商品数据、网站分析和投放结果接起来。

真正缺的不是想象力。

真正缺的是控制力。

很多人会把顺序搞反。他们看到一个很炫的 demo，就想马上全自动。更成熟的建造者，会先问一个更小、但更难的问题：

这套自动化，可靠吗？

可靠的自动化，输入要足够干净，权限要足够窄，关键节点要有人类闸门，日志要能还原发生过什么，预算要有上限，系统要有急停按钮。更重要的是，它必须在开始花钱之前，就写清楚什么叫失败。

没有这些东西的增长 Agent，不是 AI 员工。

它只是一个带仪表盘的老虎机。

## 钱让反馈变真实

Marketing Agent 虽然麻烦，但它也特别有价值，因为钱会让反馈变真实。

很多 AI 工作很容易停在“感觉不错”。答案很顺，页面很好看，策略文档很完整，大家都点头。可是这些东西还没有碰过现实。

营销没那么容易自欺欺人。

有人点了，或者没人点。有人买了，或者没人买。成本涨了，转化率跌了。某一类用户来了，但留不住。某个话术带来的不是好客户，而是一堆便宜噪音。

这些反馈有噪声，也有归因问题，但至少不是凭空想象。

这也是为什么它对小团队、一人公司特别重要。AI 已经把“能不能做出来”这个问题往下压了很多。更多人能做一个原型、一个工具、一张页面、一门小课、一个服务包。

但东西做出来之后，下一堵墙立刻出现：

有没有人看见？对的人能不能听懂？信任能不能建立？这个报价能不能经受真实买家的检验？系统能不能从失败里学习，而不是把创始人变成一个 24 小时盯后台的人？

最后这个问题，才是 Marketing Agent 真正有价值的地方。

不是按一下按钮，增长就来了。那是幻想。

真正的价值是：让一个小团队，甚至一个人，也能搭出持续学习的增长循环；同时，人仍然把注意力放在判断上。

人不应该永远手动拖每一个按钮。

但人也不应该从系统里消失。

人的位置会上移：目标、约束、品味、伦理、预算、定位、用户理解、异常处理。

这不是锦上添花。

这些就是控制层。

## 最危险的指标，看起来会像成功

真正可怕的失败，通常一开始不像失败。

明显的失败反而好处理。广告花了钱，没有转化；创意太丑，被平台拒了；获客成本高到离谱。这些失败当然痛，但至少它们会大声告诉你：我失败了。

危险的是：指标变好了，生意变差了。

Agent 找到一个更便宜的人群，但这些人永远不会留下来。它写出更刺激的文案，点击率上去了，信任下来了。它发现打折能提高转化，于是慢慢把客户训练成只等折扣。它优化线索数量，结果销售流程里塞满了不合格名单。它发现争议能带来注意力，于是品牌一点点变成创始人自己都不想成为的样子。

所以，“数据驱动”还不够。

数据不会告诉你，你愿意成为什么样的公司。

数据不知道哪些客户应该拒绝。

数据也不理解，有些注意力之所以便宜，是因为它用尊严、清晰度和长期信任换来的。

市场是裁判，但市场不是唯一的裁判。

一个健康的 Marketing Agent，需要同时接受好几个裁判：表现指标，因为没有收入的好感只是表演；品牌边界，因为没有信任的收入会变成债务；客户质量，因为不是每一个买家都让生意更健康；预算上限，因为学习不能变成流血；人工审核，因为有些决定会改变你是谁，不能随手外包。

重点不是把所有事情都变慢。

重点是让速度可以被承受。

## 先造刹车，再造发动机

如果 Marketing Agent 真的跑起来，增长岗位会被重新定义。

过去的增长运营，要花大量时间做具体动作：写不同版本，看后台，调出价，做周报，复制数据，盯账户。很多重复动作会被 AI 压缩。

但压缩不会取消责任。

压缩只会让责任暴露出来。

新的增长角色，更像系统设计师，而不是一双执行的手。他要决定循环可以优化什么，不能优化什么；要定义受众边界；要判断什么才算有意义的转化；要检查异常；要判断一个看似成功的 campaign 有没有吸引到正确的人；要防止系统把“更忙”误认为“更好”。

这又回到我一直相信的那句话：

AI 应该让人变强，而不是变懒。

如果 Marketing Agent 只是让一个平庸的操作者把更多平庸内容喷到更多渠道，那它只是让世界更吵。

如果它帮助一个认真做事的人更快测试假设、保留证据、从市场学习，把注意力从重复劳动转移到判断上，那它就真的让人变强了。

同一个工具，两种结果。

差别不在工具本身。

差别在工具外面那个循环。

我不认为多数小团队最早需要的是全自动 Marketing Agent。真正可用的版本，很可能会“无聊”得多。

它会从被允许的数据源里读取客户语言。它会生成假设，而不是宣布真理。它会提出创意，但发布前需要批准。它会从很小的预算开始。它会在花费超过阈值、但信号不足时自动暂停。它会总结这一轮改了什么、试了什么、学到了什么、下一步建议什么。它会记住失败过的角度，避免团队每个月都付钱重新学同一课。

这听起来没有“AI 营销部门”那么刺激。

但这更接近信任真正长出来的样子。

每一种强自动化，在启动前都应该先问一个听起来很不野心勃勃的问题：

这个系统永远不可以做什么？

永远不能超过这个预算上限。永远不能在这些类别里未经审核就发布。永远不能擅自改变定位。永远不能触达这类客户。永远不能隐藏不确定性。永远不能把短期指标当成长期价值的证明。

这些不是对智能的限制。

这些是让智能站得住的骨架。

未来的 AI 增长工作，不会属于最会批量生成素材的人。素材生成会越来越便宜。真正有价值的，是把用户真实语言、创意判断、平台机制、商业账、人的边界，连接成一个可以复利、但不会丢掉灵魂的循环。

这已经不是“会写提示词”了。

这更像是在建一个小机构。

一个人可以运行它。一群 Agent 可以承担重复劳动。但只要它开始接触市场、花钱、影响用户，它就需要规则、记忆、预算、仪式、复盘和后果。

所以我说，最难的 Agent，是那个会花钱的。

钱会逼系统见到现实。钱让学习贵到值得认真。钱能验证一个 offer 到底活没活着。钱也会快速惩罚粗糙的自动化。

我并不期待那个“创始人睡觉时自动长公司”的魔法营销 Agent。

我更期待一个朴素一点的机器：它能少量花钱，诚实学习，及时停止，保留证据，并且让人类在每一轮之后判断更锋利。

增长不是按钮。

增长是一个带预算、带记忆、带良心的循环。

先把这些造出来。

再让 Agent 跑。
